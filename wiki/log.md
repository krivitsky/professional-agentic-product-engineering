## [2026-07-05] fix | Tip 5.4 filename/H1 mismatch — Windows-unsafe `"` character

Found while diagnosing a Windows `git clone` failure: the repo's committed filename for Tip 5.4 is `Tip 5.4 — Replace "remember to run tests" with a hook.md`, using literal straight double quotes — invalid on NTFS, so `git clone`/checkout fails outright on Windows (`error: invalid path ...`, `fatal: unable to checkout working tree`). The local working copy had a stale workaround (filename used `_..._` in place of the quotes) that was never applied to the H1 or the 3 inbound `[[wikilinks]]` (Tier 5 hub, Tip 5.3, Tip 5.5) — those still had straight quotes, so the link never resolved in Obsidian either.

Fixed by renaming the file, its H1, and all 3 inbound links to use Windows-safe curly quotes `“ ”` (U+201C/U+201D) instead of straight quotes — same substitution precedent as the division-slash fix for Tip 5.5. `guide.md` itself is untouched (its plain-text tip title isn't a filename, so straight quotes there are fine). Verified: 0 remaining references to the old title in any form, wikilink resolves.

Still needs a PR upstream to `krivitsky/professional-agentic-product-engineering` — this local repo has no `.git`, so the fix only lives here until it's contributed back.

## [2026-07-25] edit | Voice audit — strip personal narrator from the guide

Alexey flagged `guide.md`'s Big Idea line "Don't take that **from me** — take it from the person who spent two decades telling the industry the opposite": first-person authorial voice is unacceptable register for the guide, which must read as impersonal. Audited all 30 pages via four parallel subagents (front matter + `web/build.mjs`, T1–T3, T4–T6, T7–T8) against a rule that flags author `I/me/my/we/our` but exempts second-person `you` (the guide's intended register) and first person inside quoted or example material (Uncle Bob's tweet, the Vestin testimonial, ✅ Prefer example prompts, the sample `SPEC.md` user story, `coach me` as a literal command).

Two real violations, both fixed: "Don't take that from me" → "Don't take it on faith"; and in the Tier 4 intro "This is why **we don't need to invent** new techniques…" → "This is why **agentic quality needs no** new techniques…" — the only author-`we` in the whole guide. Three minors also applied on Alexey's call: "**Don't be scared** — it's the same loop you already built" → "**Less new than it looks** —" (Tier 8 intro; the only line instructing the reader's feelings), `### The honest part` → `### The reality check` (heading presupposed a narrator choosing when to be candid), and `### Which tier do I need?` → `### Which tier do you need?` — the reader's "I" rather than the author's, but the guide's only first-person heading. That last one moved the public anchor to `#which-tier-do-you-need`, so the guide's Contents link, `CLAUDE.md` (×2), and [[The Eight Tiers]] were updated in the same pass; [[Tier 8 — Agent Execution Layer]] took the "reality check" rename.
